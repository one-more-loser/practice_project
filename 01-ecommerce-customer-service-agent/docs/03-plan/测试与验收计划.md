## 1. 验证层级与工具建议

| 代号 | 证据含义 | 不能证明 |
| --- | --- | --- |
| S | 文档/字段/契约/版本/来源静态核对 | 代码存在、服务启动、业务/模型通过 |
| U | 有独立业务预期的单元/组件测试，金额/状态/时钟/字段断言 | 真实PG事务、实际浏览器/模型和网络 |
| C | 明确替身的API/模型/02/03契约、故障注入 | 真实服务/真实模型质量或跨项目联调 |
| D | 隔离真实PostgreSQL/pgvector，事务/权限/视图/迁移/对账 | 实际浏览器、模型或跨进程网络 |
| H | 实际服务进程的HTTP/WS/SSE网络协议及身份/重连 | 单凭TestClient/内存调用不得标真实网络验证 |
| B | 实际桌面Chrome/Edge、前端页面及键盘/焦点/错误路径 | VTU/快照/构建通过不能代替；默认测试浏览器不能代替所需版本范围 |
| M | 配置的真实客服对话/SQL/Embedding/重排API，固定服务修订 | 模型卡/协议替身/微调工程报告不能代替本项目效果 |
| L | 真实并发/至少两API进程/故障/负载及连续可用测量 | 顺序重放/模拟时钟不能冒充并发或8小时可用性 |
| X | 双方实际服务、身份、共同契约及版本下的02/03真实联调 | 01替身/预留接口不等于对方已实现或共同批准 |

建议后端pytest、前端Vitest＋Vue Test Utils、浏览器Playwright。官方资料支持夹具/参数化、Vite配套测试、Vue组件交互及浏览器断言；具体版本与Node/Python/框架兼容由T-CS-001实测锁定，计划编写时未安装或运行；后续B0实际组合与局部证据见实施记录。[pytest夹具](https://docs.pytest.org/en/stable/how-to/fixtures.html)、[参数化](https://docs.pytest.org/en/stable/how-to/parametrize.html)、[Vitest](https://vitest.dev/guide/)、[Vue Test Utils](https://test-utils.vuejs.org/guide/)、[Playwright断言](https://playwright.dev/docs/test-assertions)

测试expected由基线规则/人工可复算样本独立给出，不能调用被测分摊/授权算法生成expected。金融、状态竞争、越权和恢复必须测行为，不写一组仅复述方法调用的测试。单元/替身先完成可以推进任务，但AC只在其必需真实层级和所有必验分支完成后记通过。

| 案例/Skill | 已完成处理来源、独立回归与留出集、未审/不适用/过期/越权/缺证据样本 | 训练/归纳来源与验收用途隔离；已入案例的问题不计独立未见提升 |
| 参考容量/可用性 | 500订单/50SKU/200知识片段、10并发、固定版本/资源；至少200预热请求 | 真实15分钟负载、真实连续8小时探测；模型/网络慢与故障不从样本删除，业务时钟不能替代 |

## 6. 证据目录、状态与缺陷处理

后续证据拟保存`docs/06-acceptance/AC-CS-xxx/<run_id>/`；当前未创建这些运行文件。每个manifest至少记录ac_id/run_id、REQ/DESIGN/PLAN版本、status、evidence_levels、实际代码/依赖/服务/DB/模型/Schema/数据/索引/政策版本、输入/标准结果/实际断言、实际复现命令、脱敏日志/结果路径、开始结束时间、失败/重试/限制及对应任务。密钥仅存引用，完整PII不入证据。

完整合成收货字段仅保留在获准测试源/个人业务记录，证据保存引用/掩码；断言失败、HTTP抓包和浏览器追踪也需脱敏，不能因数据是合成就把整段地址/电话打印到通用报告。测试源有字段与日志可见全文是两件事。

状态使用not_run/partial/pass/fail/blocked_external/condition_not_triggered，逐分支记录；partial/静态/替身不能汇总成真实通过。修复先留失败，再运行受影响用例及关键硬规则回归，不为凑通过删除困难样本、放宽阈值或扩大权限。截图只辅证界面，不替代数据库对账/API断言；代码存在/测试收集/启动成功不证明业务验收。

高风险缺陷（越权、泄密、重复/超额资金、负余额、错误状态/审批旁路、消息持久丢失）解决并回归前禁止V1通过。其他缺陷按影响声明处理，不借P1优先级掩盖基线缺项。T-CS-024提交集成验收候选，用户评审通过后再进入部署交付阶段。
