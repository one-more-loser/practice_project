# 模型接入增量设计

实施结果见[模型接入实现与复现](../04-implementation/模型接入实现与复现.md)。本设计的小规模真实服务验证已完成；全规模质量、稳定性和负载仍待验，不把配套安装当作完整兼容通过。

2026-10-23。用户已确认Qwen并授权开始接入、共享模型下载目录；主客服与临时SQL限定deepseek-flash。不重开需求、不修改已应用迁移、不替03选择最终微调模型。

- 生成服务：DeepSeek官方API，chat/sql独立能力，protocol为deepseek-chat，限制model=deepseek-flash，显式thinking disabled。使用既有DEEPSEEK_API_KEY环境变量；CS_CHAT_API_KEY/CS_SQL_API_KEY显式配置优先。真实密钥不写JSON/命令行/日志。
- 临时SQL适配：将通用模型返回的query/clarify/unsupported/error转换到XCS-SQL-v0.1；缺省传输修订由适配器绑定本次请求，已返回冲突修订拒绝，SQL/参数绝不补造。仍经过原独立SQL权限/结构/成本校验；成本阈值未校准继续关闭执行。
- 本机模型：共享只读HF快照＋01项目独立Python环境。Embedding为Qwen3-Embedding-0.6B、1024维、末token/L2、固定query指令和document原文；重排为Qwen3-Reranker-0.6B，官方前后缀模板、yes/no logits。新协议qwen-embeddings携带input_type=query/document；不影响旧openai-embeddings协议。
- 服务：127.0.0.1:8010，POST /v1/embeddings与POST /v1/rerank，GET /health。每个请求固定模型枚举，不提供通用生成或数据库功能。单进程两模型常驻、共享GPU门，等待队列有界，取消连接时不释放仍在执行的GPU槽位。输入超编码预算返回422，不静默截断或转CPU。
- 模型/依赖：下载脚本固定HF提交并校验整文件SHA256，未完成快照没有verified-model标记；本地服务启动重新检查manifest及全部文件摘要，local_files_only、trust_remote_code=False。共享目录仅用于已批准模型及其清单，兄弟工程不被改写。
- 评测：常规pytest显式禁用本机真实服务配置，避免运行回归触发付费调用。真实API/权重评测使用独立有界脚本，分别记录协议、质量、显存/耗时与业务验证，旧181项测试不替代此增量。

选择证据与适用限制见[Embedding评估](../04-implementation/Embedding选型评估.md)。本轮执行状态后续记录于模型接入实现与复现，尚不能凭本设计宣称所有真实模型验收通过。
