# V1增量数据字典

2026-10-23。由当前SQLAlchemy元数据导出，真实Schema比较差异0；0016～0020已应用。仅列原38表之外的19表。类型与约束证明结构，不替代流程、权限或数据质量验收。

订单、明细、余额及流水仍是权威；会话/检查点/审核任务不替代业务账本。wire金额用CNY整数分字符串，数据库使用BIGINT。字段可空以业务状态为前提，例如审批人/执行时间在审核前为空，成功后由状态及服务条件约束。

特别说明：support_summary_snapshot.snapshot_id是内部修订行ID；payload.snapshot_id为对外按窗口稳定的快照ID，消费者按payload ID/revision替换，不累加修订。案例/Skill定义是声明性步骤，不能存新工具、权限或可执行代码。
