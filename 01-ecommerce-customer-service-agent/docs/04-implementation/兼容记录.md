## 处理记录

1. EDB17.11在本机中文目录的initdb后置SQL阶段出现UTF8编码错误。运行脚本创建一个临时DOS路径别名指向本项目.runtime（本次Z:），PG通过该别名启动；核对目标时解析回真实项目路径。没有更改注册表、系统区域或把数据移到其他目录。停止脚本会撤销别名，保留数据。盘符占用或目标不符时拒绝继续，不覆盖其他映射。
2. 初次运行发现应用角色不能读取Alembic版本。以增量`0003_readiness_grant`授予该表SELECT；没有给予建表、身份修改或审计改写权限。空库与历史升级均包含这次迁移。
3. 明确使用`Depends(..., scope="function")`，保证事务提交先于成功响应。真实PG延迟触发器制造提交失败时，返回503、不给登录Cookie、无会话落库。故将FastAPI最低声明改为0.121；实际锁定0.159.1。
4. Element Plus按组件引入；组件样式放在工程入口，避免jsdom测试把外部CSS当作Node模块加载。前端构建及测试均重新通过。
