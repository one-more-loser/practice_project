# B1实际数据字典

版本：DATA-CS-B1-v1；Schema `0010_business_integrity`；2026-10-22。本文件只列B1已实现的21张表，B0身份/私密输入沿用既有字典，后续域仍按所属任务增量补齐。元数据生成字段清单不是业务验收，真实迁移/空值/约束核对见B1证据。

共用字段：store_id为店铺；source_kind标明synthetic/derived/business_import；data_batch_id和batch_generation为批次/代次；version为并发版本；created_at/updated_at为UTC时区时间。下列必填指数据库不允许NULL；有默认值的字段可以由服务端补入。所有`*_minor`金额为CNY整数分，API输出字符串；数量为整数。`*_at`为带时区时间；`*_ref`/`*_id`是受控关联引用，不能由模型决定身份。

收货快照的recipient/phone/province/city/district/street/postal_code属于私密字段，只在专用本人页面返回完整内容；其他通道使用引用/白名单脱敏。confirmation和operation只记录参数引用/摘要，不能复制原始私密输入。

当前业务政策为包邮、无促销；优惠/运费/应付/已付/已退字段保留。cost_minor、supplier_ref和external_id未知时NULL，不填伪造来源。
