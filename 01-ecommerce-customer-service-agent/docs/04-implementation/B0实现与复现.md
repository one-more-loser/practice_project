# B0实现与复现

版本：IMPL-CS-B0-v0.1，2026-10-22。范围：用户已批准的T-CS-001～003；需求/设计/计划编号不变。B0提交评审，B1未开始。

## 工程及调用链

`frontend/src/main.ts → Router/Pinia → FoundationPage`提供工程状态页。状态页只探测`/health/ready`；提示明确区分B0数据库基础与尚未实现的业务/模型。没有伪造商品、余额、客服应答或可操作工作台。

`HTTP → request_boundary → 契约验证 → Origin/会话/CSRF → TrustedContext → 归属策略 → 字段投影/审计 → 提交 → 响应`。本轮入口在[main.py](../../backend/src/cs_agent/main.py)和[身份API](../../backend/src/cs_agent/identity/api.py)。服务端生成request_id，忽略请求自报身份；错误信封不回显原始输入、SQL、完整资料或凭据。应用日志只记请求ID、方法和状态，启动命令关闭访问日志。

| 实际入口 | B0行为 |
| --- | --- |
| GET /health/live | 进程可访问；不代表DB、模型或V1可用 |
| GET /health/ready | 核对B0数据库及Schema；不可用503。四类模型均标unvalidated，业务标not_implemented |
| GET /api/v1/public/service-info | 游客及登录主体可访问的公开工程信息；商品/政策查询留到对应任务 |
| POST/GET/DELETE /api/v1/session | 预置账号登录、当前会话/CSRF、带Origin及CSRF的退出；无注册产品 |
| PATCH /api/v1/session/role | 仅切换当前主体有效持有的角色，记录前后角色；不合并兼任权限 |
| GET /api/v1/me/shipping-inputs/{id} | 仅本人受控输入读取，可含完整资料；他人和不存在统一404 |

认证会话维护使用会话令牌、Origin、CSRF及撤销状态，不创建资金/订单operation；业务写入的确认/Idempotency-Key/operation由T-CS-004建立。本次未放开任意execute或通用数据库接口。

密码以PBKDF2-SHA256/600000轮及独立盐保存；会话使用随机令牌，只存令牌/CSRF摘要。HttpOnly、SameSite=strict，Secure默认开启；本机回环HTTP验证显式关闭Secure，不代表生产TLS方案已经验收。会话默认8小时，为实现默认；更改需回归到期、退出、撤权及恢复检查。停用、授权版本变化、角色撤销/有效期、批次失效在下次受控读取前重新检查；已识别但失效的会话保留拒绝归因，不能作为授权上下文使用。

客服只按当前有效分派读取；主管仅本店；店铺管理员走独立履约读取能力，知识角色不能读取个人服务数据。B0没有生产分派/履约读取API：HTTP测试专用入口用受控分派事实替身调用真实身份、PG、策略及投影，不随生产create_app注册。真实工单/改派仍由T-CS-015/016交付。

## 数据骨架及来源

三个增量迁移：`0001_source → 0002_identity → 0003_readiness_grant`。实际七张业务基础表：source_batch、store、subject、staff_role_grant、login_session、shipping_input、audit_event；另有Alembic版本表和独立实例守卫。身份/来源采用真实FK、复合店铺与批次约束、枚举/时间条件及索引。ORM元数据与已迁移的字段/类型/关联/索引保持可比较；新增迁移不会因元数据遗漏而自动删除这些约束，迁移仍需人工审查。

shipping_input提前建立受控资料及本人读面，服务于T-CS-003的隐私边界验证；个人表单写入、订单关联与不可变ShippingSnapshot留T-CS-006，不以此替代订单收货历史。未创建钱包、订单、商品、库存、工单、检查点或知识表。

[合成manifest](../../data/synthetic/manifest.json)固定种子、代次、来源时间、模拟账号和后续容量批次规则；[字段来源映射](../../tests/fixtures/source_map.json)逐实体列必填/条件必填/可空及来源。8个模拟账号、2份受限资料，密码随机生成，业务来源指纹不包含随机密码摘要。重复导入校验指纹，不重置停用/角色/会话等业务状态。开户零元；B0不建钱包、不赠款、不模拟非零余额。500订单/50SKU/200片段只登记后续生成规则，尚未生成，不冒充性能测试数据。

数据库实例位于`.runtime/pgdata`，仅回环55432；库为cs_agent_b0、cs_agent_b0_test、cs_agent_b0_upgrade。迁移前核对URL/当前数据库/角色/端口/实例标识/项目路径/实际data_directory；运行角色和迁移角色均无superuser、CREATEDB、CREATEROLE或BYPASSRLS。只有迁移角色拥有业务表；运行角色不能建表、改身份/角色或修改/删除审计。守卫由实例初始化角色拥有，应用与迁移只读。运行账号暂属后端应用数据账号；以后受控SQL必须另建只读受限读面，不能把这个账号交给SQL模型。

API测试仅重置固定_test库，升级测试仅清理固定_upgrade库；均先核对目标，不清应用库或旧项目，不提供任意URL重置入口。没有对业务库提供自动破坏性降级。

## 隐私门面及限制

员工投影白名单只有受控引用、电话末四位及省市掩码，原始收件人、区县街道不进支持DTO；异常结构值保守遮盖。审计摘要仅接收机器原因码、角色和整数版本；不直接序列化请求对象。字段投影、错误响应和实际请求日志已有断言，真实HTTP也另作探测。

`external_text`用于后续消息/模型/追踪入口：规范化、电话遮盖、疑似地址或变形电话转个人表单。它目前只有单元验证，尚未接入不存在的模型/会话入口；正则不能证明任意自然语言隐私安全。T-CS-010/011/022必须覆盖完整消息、工具、模型、检查点、导出与错误链路。导出业务、知识可见性和个人表单行政区校验也随对应任务回归，不能从B0门面推定通过。

## 复现

在本项目根目录PowerShell执行；已有依赖已锁定。运行前确认本项目无其他测试进程，API测试共享_test库，不能并行跑两套重置测试。

```powershell
# 全套基础检查；会启动项目PG，结束后停止项目PG并撤销盘符别名，保留数据。
.\scripts\check.ps1
```

脚本显式用已有Node24运行npm-cli，避免npm.cmd选回默认Node22。可通过`-Node`和`-NpmCli`指定已核对的只读工具路径；默认路径及真实版本见兼容记录。首次重装使用项目缓存，不能去旧工程运行：

```powershell
$env:UV_CACHE_DIR = "$PWD\.runtime\uv-cache"
$env:UV_PYTHON_DOWNLOADS = 'never'
$env:TEMP = "$PWD\.runtime\tmp"
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Force -Path $env:TEMP | Out-Null
uv sync --project backend --locked --group dev --python 'C:\Users\27997\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
$nodeExe = 'C:\Users\27997\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe'
$npmCli = 'C:\Node.js\node_modules\npm\bin\npm-cli.js'
$env:PATH = (Split-Path -Parent $nodeExe) + ';' + $env:PATH
& $nodeExe $npmCli --prefix frontend ci --no-audit --no-fund
```

若重建时缺PG二进制，在[EDB官方页](https://www.enterprisedb.com/download-postgresql-binaries)取得本次17.11-3 Windows x64 zip，保存到本项目`.runtime/downloads/postgresql-17.11-3-windows-x64-binaries.zip`再执行检查。不要运行全局安装程序。环境记录里的归档指纹用于复现核对，不能替代来源签名验证。

单独启动用于本地查看（均非部署）：

```powershell
.\backend\.venv\Scripts\python.exe scripts/dev_database.py start
.\backend\.venv\Scripts\python.exe scripts/migrate.py app
# 开一个项目内终端运行后端；前端代理同源入口使用5173。
.\backend\.venv\Scripts\python.exe -m uvicorn cs_agent.main:app --env-file .runtime/local.env --host 127.0.0.1 --port 8000 --no-access-log
# 另一个终端：显式设置上述$nodeExe、$npmCli和PATH后
& $nodeExe $npmCli --prefix frontend run dev
# 用完关闭开发服务，再停止项目PG；不删除数据。
.\backend\.venv\Scripts\python.exe scripts/dev_database.py stop
```

本地凭据只在被当前用户ACL限制且被忽略的`.runtime/db-secrets.json`、`local.env`、`demo-accounts.json`；不得复制到前端、聊天、公开证据或版本控制。原始演示密码不在本文输出。具体安全存储/部署参数仍在部署阶段评审。
