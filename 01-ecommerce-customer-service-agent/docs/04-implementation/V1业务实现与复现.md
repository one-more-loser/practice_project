## 2. 权限与交易关键点

身份来自后端会话；客服详情以当前有效分派为门槛，主管仍限本店。工单关联订单由服务端绑定顾客后读取，并强制使用脱敏投影。电话只留末四位，地址到市；没有员工解密入口。案例生成不发送源顾客、工单、订单或员工引用，密钥不进入模型上下文。

金额使用CNY整数分。退款占用与成功数量/金额分开；已拒绝/撤销才释放，已退款单位序号不可再次使用。独立样本验证商品10000分/3件：先退3333，再退6667；原运费1000不退，原实付11000最终只退10000，不标为原实付全退。申请、审核、退货单号均不提前入余额。库存只计店铺实际收到的可售数量。

会话模式与任务租约分别使用epoch和fence。消息编号/ACK/去重为持久事实，WebSocket断开不结束人工，不撤销已成功业务。工作台迟到输出不能覆盖新模式；改派后旧员工HTTP和WS均撤权。业务页面提案与会话提案分开绑定，模型生成的提案在人工模式切换后失效。
