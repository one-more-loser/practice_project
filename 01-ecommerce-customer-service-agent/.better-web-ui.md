## Design Context

### Users
已确认：模拟电商的电脑浏览器顾客、获分派客服、主管、店铺及知识管理员。核心任务为购物、本人订单/余额、客服协同和店铺履约；不新增手机适配或原生客户端。

### Brand Personality
用户已选择“暖白＋橙色，更突出促销与购物氛围”，并要求采用GitHub上的Apple UI设计Skill。表达清晰、亲切、有秩序；商品与业务事实先于装饰。

### Aesthetic Direction
采用项目内`.agents/skills/apple-hig/SKILL.md`作为设计与复核参考，来源daft2/apple-hig-skill，固定提交d7fb4531db34115c2dd7c2089abd3641362a8a98，MIT许可保留。它是社区整理的Apple官方HIG，并非Apple官方发布的Skill。

桌面网页采用内容优先、留白、对齐、克制层级与反馈；暖白背景、橙色主要操作、文字明确的状态。Apple平台pt尺寸不机械当作CSS像素，也不将原生控件、Apple Pay、登录方式或移动设备规则扩展为本项目需求。玻璃效果只作可选导航表面，表格/表单保持实底可读。不加载SF字体/SF Symbols或Apple品牌资产。

### Implementation Defaults
已批准Vue3＋TypeScript＋Vite、Vue Router、Pinia、Element Plus。保留现有表单/表格能力，不另加组件或表单框架。Pinia仅存客户端视图，金额/次数/状态以后端为准。主要内容字号16px，系统可用中文字体；8px间距节奏，按钮与字段具有标签、焦点、等待、成功与失败状态。暖白＋橙色为用户偏好，具体色值/尺寸属于可调整实现默认。

### Design Principles
1. 商品、总价、订单事实和下一步操作有清楚层级；不伪造促销、评价、库存或未实现客服。
2. 每个任务区域有一个清楚的主要操作；普通状态内联显示，资金/地址意图展示摘要后明确确认。
3. 状态同时用文本表达；支持键盘焦点、浏览器缩放和减少动画，不依赖颜色或鼠标悬停。
4. 界面隐藏完整员工联系信息；不以按钮灰显代替后端鉴权。
5. 设计偏好不改变需求基线、权限或技术主干；浏览器实测后再声明界面验证结果。
