# 协作规则

1. 使用第一性原理思考，先确认真实目标、约束和成功标准，不套用惯例。
2. 简单问题直接回复；复杂任务使用answer-me-with-html。该Skill不可用时说明情况，保留HTML结果呈现。
3. 执行新任务先读[HANDOFF.MD](HANDOFF.MD)，把本项目踩过的坑追加到该文件。
4. 默认使用Codex浏览器和Chrome；控制Vivaldi前先问用户。
5. 上线、部署、生产环境任务必须考虑并验证性能开销。
6. UI避免不必要的次级标签和说明，让布局表达层级。
7. 中文回答减少副词。

项目事实和执行边界以用户最新指令、已批准规格及[实施记录](docs/04-implementation/README.md)为准。UI上下文见[设计记录](.better-web-ui.md)；Apple HIG副本位于`.agents/skills/apple-hig/`。
