## Design Context

### Users
用户已确认：桌面浏览器店长/运营/获准查看者；从统一管理入口看经营状态、问数、编制完整可行方案、审批及明确发布。01交易/活动事实与02方案分开，但属于同一店铺产品。

### Brand Personality
沿用用户明确要求的01暖白＋橙色。清晰、亲切、有秩序。主要任务是经营判断，层级由布局、对齐、数值表和操作状态表达，减少副标签/重复描述。

### Aesthetic Direction
参考用户指定daft2/apple-hig-skill；01现有固定提交d7fb4531db34115c2dd7c2089abd3641362a8a98为参考，不机械套用原生Apple pt尺寸或添加登录/支付平台需求。背景#fcfaf7、文字#352b25、主要操作#b9491c、次文字#736a62、分隔#e7e1d8。中文易读字体、表格数字对齐、留白、克制圆角与实底；不加无意义图表或营销大标题。

### Implementation Defaults
Vue3＋TypeScript＋Vite，简单表单/表格先用原生HTML/CSS，不提前引入整套额外组件框架。金额/权限/约束以后端为准；缺数、依赖未接、演示数据、未知执行结果须明确，不模拟业务成功。键盘焦点、禁用/等待/错误与可恢复状态齐全。

### Design Principles
1. 方案/依据/约束/决策先于装饰；每个区域一个主要动作。
2. 暖白与橙色与01同源；状态同时用文字表达。
3. 演示与真实接入有清楚边界，不用假发布按钮制造进度。
4. 先确认方案，再显式发布；不由模型或前端改变金额/权限。
5. 完整表格金额和关键操作在桌面/缩放时可读，细节按需展开。
