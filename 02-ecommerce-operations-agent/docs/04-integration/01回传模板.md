## 脱敏样本包

逐文件给路径、SHA256、来源与参考时钟，保持引用可勾稽；模拟店铺仍标synthetic。

1. 店长/运营/查看者的session能力样本；顾客、另一店、撤权/过期失败样本（移除实际Cookie/CSRF令牌值）。
2. 一份完整经营Snapshot JSON或CSV包：订单头/行/退款、SKU/价格版本/成本null语义、时点与revision；不含姓名/电话/地址。
3. 对应方案manifest、预检、02 grant请求/响应、唯一slot/活动引用；给摘要生成规则与可比对期望值。
4. committed、phase更新、closed_no_effect完整回执；404/超时/unknown、提交与取消/到期竞争、迟到发布被拒绝的请求/结果。
5. 报价→2件订单→支付18400→退款9200→净支付9200样本；活动修订、库存/让利预占/核销/释放勾稽；退款不恢复营销额度。
6. 同活动实际revision 1/2及迟到退款、重复/乱序/水位样本；金额/销量与上述账本勾稽，缺费用不报实际利润。

## 验收证据与剩余项

- 精确命令、环境/数据库/样本/参考时钟、首次失败及修复、最终结果和日志/截图路径；样本及证据有SHA256。
- 真实HTTP与统一登录页面：发布、商城展示/quote/购买、暂停/恢复/结束、已创建订单承诺、旧报价失效、回执重送/重启。
- 真实DB并发：同审批双客户端不同键、预算/数量/库存边界、cancel/finalize/发布竞争、超时unknown和迟到屏障；保留既有无活动交易回归。
- 性能：同环境同负载无活动/有活动quote及create_order的样本量、P50/P95、P95差额、查询数、锁等待、资源；新增开销目标≤50ms，未达标列原因；断开02/模型后已发布活动仍能交易。
- 分开列出“已实现且验证”“实现未验”“未实现”“02需适配”“业务提供方未供数据”；不能把缺失首发链路列成可选迭代。
